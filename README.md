# Huizenzoeker

Huizenzoeker zoekt automatisch woningen op Immoweb op basis van meerdere zoekprofielen.

## Functies

- Meerdere zoekprofielen
- Zoeken op postcode, woningtype en prijs
- Automatisch uitlezen van woninggegevens
- Detecteren van nieuwe advertenties
- Eigen CSV-bestand per zoekprofiel
- Gecombineerde HTML-e-mail
- Logging
- Automatische uitvoering via Windows Taakplanner
